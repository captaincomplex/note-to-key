# One Note, Everywhere — Guitar Theory

An interactive, browser-based guitar theory trainer for learning:

- every position of a selected note on the fretboard;
- root, third, and fifth interval roles;
- major, minor, diminished, dominant 7, major 7, and minor 7 chords;
- the circle of fifths, relative minors, key signatures, and I–IV–V–I progressions.

## Live site

https://one-note-everywhere-fretboard.jazzykoala516.chatgpt.site

## Run locally

Serve the repository directory with any static web server, then open `index.html`.

## Guitar audio

The instrument uses six real steel-string recordings from [Meta Open Sound](https://github.com/facebookincubator/Meta-open-sound), one for each physical guitar string. The recordings are dedicated to the public domain under CC0 1.0 Universal. A copy of the audio license is included at `audio/LICENSE-CC0.txt`.
